# Design Language

## Product Character

Cabzone is a practical ride-hailing product intended for riders, drivers and city-level operations.

The UI should prioritize:

- Clarity
- Speed
- Trust
- Legibility
- Low cognitive load
- Strong status communication

## Rider

Important information should be immediately visible:

- Pickup
- Destination
- Suggested fare
- Proposed fare
- Driver details
- Ride status
- Payment status

## Driver

The driver interface should prioritize:

- New ride offer
- Fare
- Pickup distance/location
- Destination
- Accept/decline
- Current ride status
- Wallet status

## Admin

The admin interface should prioritize:

- Tables and filters
- Application status
- Zone geometry
- Pricing configuration
- Disputes
- Audit history

## Status Design

Ride states should have visually distinct status treatments.

Avoid communicating critical state only through color. Include text/icons.

## Maps

Map interactions must not hide the primary action.

Zone editing must clearly distinguish:

- Current boundary
- Selected zone
- Proposed changes
- Saved state

## Accessibility

- Maintain readable text sizes.
- Ensure sufficient contrast.
- Do not use color as the only status indicator.
- Make primary actions easy to identify.
